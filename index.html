Each tap on an NXP NTAG 424 DNA chip produces a one-time signed URL (SUN message). A copied tag replays an old counter, so the server rejects it. Counterfeit and copied cards simply stop working.

Fleet controls

  • Someone leaves the company: their card is reassigned or killed from the admin console, same day as the HR offboarding event.
  • Lost card: one-tap revoke, and the replacement ships with the same profile.
  • Every physical card has a serial, owner and last-tap date, so IT can audit hardware like laptops.

Why split it this way

  • Buy chips from authorized NXP distributors, not the card factory. Counterfeit NTAGs are common and you can't run 424 DNA security on a fake.
  • Load the encryption keys yourself after import. The factory never holds them, which is a clean SOC 2 story.
  • Keep a second card supplier in Vietnam or Mexico so a tariff change doesn't halt enterprise orders.
  • Sell direct to team accounts with fleet pricing, so hardware shows up on the same invoice as seats.
